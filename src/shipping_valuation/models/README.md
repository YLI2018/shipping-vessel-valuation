# Valuation models

- `age_curve.py`: M1 exponential age curve, fitted by OLS on log price (published, tested).
- `hedonic.py`: M1+ hedonic price model, models A and B (published, tested).
- `dcf.py`: M2 discounted cash flow, sale priced from earnings or the M1 curve, IRR and implied TCE (published, tested).

Further models will be added here.
