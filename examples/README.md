# Reproducible examples

This folder will contain examples showing how to run each
valuation model and interpret its results.

- `run_age_curve.py`: M1 age curve, values Target Ship 1, back-test and charts.
- `run_hedonic.py`: M1+ hedonic model, step by step: fit, effects, value, back-test and charts.
- `run_dcf.py`: M2 DCF, step by step: discount rate, cash by year, sale price on both bases, price tests and the long-run TCE chart.
